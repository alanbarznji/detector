# نظام المراقبة والإنذار - Detector Dashboard

نظام متكامل لمراقبة الكاميرات والحساسات مع نظام تنبيهات متقدم.

## المميزات

### 📊 لوحة التحكم (Dashboard)
- عرض 4 كاميرات مباشرة
- عرض حالة التنبيهات من الكاميرات والحساسات
- إحصائيات الكاميرات (Online/Offline)
- خط زمني للأحداث الأخيرة (24 ساعة)

### 📹 صفحة الكاميرات (Cameras)
- عرض مباشر لجميع الكاميرات
- خيارات العرض: 1×1, 2×2, 3×3, 4×4
- إضافة كاميرا جديدة
- تغيير اسم وموقع الكاميرا
- حالة الكاميرا (Online/Offline/Loading)
- مؤشرات التنبيه (Fire/Smoke/PPE)

### 📡 صفحة الحساسات (Sensors)
- عرض جميع الحساسات
- القراءات المباشرة والفورية
- حالة الحساس (Working/Error/Disconnected)
- قيم Min/Max
- مؤشرات تجاوز القيم

### 📁 صفحة الأرشيف (Archive)
- عرض جميع التنبيهات
- فلاتر متقدمة:
  - حسب النوع
  - حسب المصدر (كاميرا/حساس)
  - حسب الأولوية
  - حسب الحالة (نشط/تم الحل)
- تصدير CSV
- بحث متقدم

### 📈 صفحة التحليلات (Analytics)
- رسوم بيانية للتنبيهات (يومي/أسبوعي/شهري)
- أكثر أنواع الحوادث تكراراً
- نسبة Online/Offline للكاميرات
- نشاط الحساسات

### ⚙️ صفحة الإعدادات (Settings)
- إدارة المستخدمين
- إدارة الصلاحيات
- إعدادات الكاميرات
- إعدادات الحساسات
- الثيم (Light/Dark)
- الإشعارات

## التقنيات المستخدمة

- **React 18** - مكتبة بناء واجهة المستخدم
- **TypeScript** - للكتابة الآمنة
- **Vite** - أداة البناء السريعة
- **React Router** - للتنقل بين الصفحات
- **Tailwind CSS** - للتصميم
- **Recharts** - للرسوم البيانية
- **Lucide React** - للأيقونات
- **date-fns** - للتعامل مع التواريخ

## التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- npm أو yarn

### خطوات التثبيت

1. تثبيت المكتبات:
```bash
npm install
```

2. تشغيل المشروع في وضع التطوير:
```bash
npm run dev
```

3. بناء المشروع للإنتاج:
```bash
npm run build
```

4. معاينة النسخة المبنية:
```bash
npm run preview
```
