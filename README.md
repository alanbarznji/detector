# نظام المراقبة والإنذار - Detector Dashboard

نظام متكامل لمراقبة الكاميرات والحساسات مع نظام تنبيهات متقدم ونظام كشف ذكي.

## المميزات الجديدة ✨

### 🔍 نظام الكشف المتطور
- **كشف أنواع متعددة**: حريق، دخان، معدات السلامة (PPE)
- **كشف PPE محدد**: 
  - بدون خوذة
  - بدون سترة سلامة
  - بدون قفازات
  - بدون أحذية سلامة
  - بدون نظارات واقية
  - بدون كمامة
- **عرض قدرات الكشف**: كل كاميرا تعرض أنواع الكشف النشطة
- **دقة الكشف**: عرض نسبة دقة الكشف لكل تنبيه

### 📊 التحسينات

#### 1. Dashboard (لوحة التحكم)
- ✅ عرض 4 كاميرات مباشرة مع آخر frame
- ✅ حالة التنبيهات من الكاميرات (حريق، دخان، معدات السلامة)
- ✅ حالة التنبيهات من الحساسات (غاز، حرارة، حركة)
- ✅ عرض عدد الكاميرات Online/Offline
- ✅ Mini Timeline لأهم الأحداث (آخر 24 ساعة)

#### 2. Cameras (الكاميرات)
- ✅ عرض قدرات الكشف لكل كاميرا
- ✅ مؤشرات نوع الكشف النشط (Fire/Smoke/PPE)
- ✅ Live View مع خيارات: 1×1, 2×2, 3×3, 4×4
- ✅ حالة الكاميرا (Online/Offline/Loading)

#### 3. Sensors (الحساسات)
- ✅ القراءات المباشرة والفورية
- ✅ حالة الحساس (Working/Error/Disconnected)
- ✅ قيم Min/Max مع مؤشر تجاوز القيم

#### 4. Archive (الأرشيف)
- ✅ عرض تفاصيل مخالفات PPE المحددة
- ✅ عرض دقة الكشف لكل تنبيه
- ✅ فلاتر متقدمة (النوع، المصدر، التاريخ، الأولوية)
- ✅ تصدير CSV

#### 5. Analytics (التحليلات)
- ✅ رسوم بيانية للتنبيهات (يومي/أسبوعي/شهري)
- ✅ أكثر أنواع الحوادث تكراراً
- ✅ نسبة Online/Offline للكاميرات

#### 6. Settings (الإعدادات)
- ✅ إدارة المستخدمين والصلاحيات
- ✅ إعدادات الكاميرات والحساسات
- ✅ الثيم (Light/Dark)

- **React 18** - مكتبة بناء واجهة المستخدم
- **JavaScript (ES6+)** - لغة البرمجة

- **React Router** - للتنقل بين الصفحات

- **Recharts** - للرسوم البيانية
- **Lucide React** - للأيقونات
- **date-fns** - للتعامل مع التواريخ

## التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- npm أو yarn

### خطوات التثبيت

1. تثبيت المكتبات:
```bash
npm install
```

2. تشغيل المشروع في وضع التطوير:
```bash
npm run dev
```

3. بناء المشروع للإنتاج:
```bash
npm run build
```

4. معاينة النسخة المبنية:

## نظام الكشف

### أنواع الكشف المتاحة
1. **كشف الحريق (Fire Detection)**: اكتشاف النيران والحرائق
2. **كشف الدخان (Smoke Detection)**: اكتشاف الدخان المبكر
3. **كشف معدات السلامة (PPE Detection)**: 
   - بدون خوذة (No Helmet)
   - بدون سترة سلامة (No Safety Vest)
   - بدون قفازات (No Gloves)
   - بدون أحذية سلامة (No Safety Boots)
   - بدون نظارات واقية (No Goggles)
   - بدون كمامة (No Mask)

### قدرات الكاميرا
كل كاميرا يمكن أن تدعم واحد أو أكثر من أنواع الكشف:
- كشف الحريق فقط
- كشف الدخان فقط
- كشف معدات السلامة فقط
- كشف الحريق والدخان
- كشف شامل (جميع الأنواع)
